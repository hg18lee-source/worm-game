# 초록 정원 · 지렁이 게임

`dist/index.html`을 브라우저로 열면 바로 실행됩니다. 설치나 인터넷 연결은 필요하지 않습니다.

## GitHub 업로드 준비

프로젝트 기준 폴더는 `worm-game`입니다. 업로드할 파일은 아래 4개입니다.

- `.gitignore`
- `README.md`
- `dist/index.html`
- `dist/game.js`

`index.html`은 같은 폴더의 `game.js`를 불러오므로 두 파일을 함께 유지해야 합니다.
`.openai/hosting.json`은 기존 Sites 프로젝트 연결 설정이므로 업로드 대상에서 제외합니다. 로컬 파일은 그대로 보관합니다.
`.gitignore`는 Git으로 관리할 때 적용됩니다. 웹 업로드에서는 제외 파일을 직접 선택하지 않아야 합니다.
이 준비 과정에서는 Git 저장소 생성, 커밋, 업로드, 공개 또는 GitHub Pages 설정을 하지 않았습니다.

- 방향키 또는 WASD: 이동
- Space: 시작 / 일시정지 / 계속하기
- 화면 방향 버튼 또는 게임판 스와이프: 이동
- 먹이: 10점 및 길이 증가
- 벽이나 몸에 부딪히면 게임 종료
- 속도 선택, 처음부터 다시 시작, 브라우저 최고 기록 저장 지원

최고 기록은 브라우저의 저장소 사용이 허용된 경우에만 유지됩니다.

검증: 시작, 역방향 차단, 먹이·성장·점수, 일시정지·계속, 벽 충돌, 이동하는 꼬리 칸 진입, 몸통 충돌, 재시작 초기화의 로직 검사 통과. 브라우저에서 시작과 일시정지 화면 확인.
